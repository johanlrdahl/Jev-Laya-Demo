02

Sikkerhet

Hvordan vi beskytter pasientdata

Sikkerheten du trenger

Kravene

  • GDPR: Helsedata er kategori spesiell
  • Schrems II: Kontroll over dataflyt
  • Normen: Streng tilgangsstyring

Slik løser vi det

  • All data i Azure Norway East
  • ISO 27001 og 27018 sertifisert
  • Rollebasert tilgang, full sporbarhet

Sikkerheten du trenger

Zero Trust Identity

Entra ID + Conditional Access, FIDO2 MFA, PIM for just-in-time tilgang, HelseID-integrasjon for klinisk autentisering.

Kryptering

TLS 1.3 in transit, AES-256 at rest med CMK i Key Vault. mTLS mellom alle services via Istio sidecar.

Policy as Code

Azure Policy + OPA Gatekeeper håndhever Normen automatisk. Ingen ressurser kan opprettes i strid med policy.
